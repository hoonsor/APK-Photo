# 照片整理箱

用滑的把相簿整理乾淨，而且找得回以前的照片。
照片和影片可以一起放進自己建立的相簿，多選後一次分享到 LINE、Dropbox、Google 雲端硬碟。

> 這份是給使用者看的完整說明。接手開發請看 `AGENTS.md`，版本進度看 `PROJECT_STATUS.md`。

## 這個 App 解決什麼問題

相片整理類 App 大多把「丟掉」做得很順，但「找回來」很痛苦：只能一路往下捲，捲到三年前的照片要滑很久。
這支 App 在保有完整滑動整理流程的前提下，把時間軸跳轉、日期搜尋、相似照片偵測和相簿整理做成主要功能。

- **整理**：一張一張滑，往左丟、往右留，確認後才真的刪除
- **找照片**：年份／月份一點就跳，可以搜尋日期、資料夾、檔名，可只看 LINE、截圖、影片
- **相簿**：照片和影片放在同一本；同一張可以同時在好幾本；不會搬動或複製檔案
- **分享**：多選後一次送到 LINE、Dropbox、雲端硬碟

## 隱私

- 照片不會被上傳到任何地方：網路權限只用來向 GitHub 檢查與下載 App 更新（v1.2.0 起），照片、相簿、位置都不會經過網路
- 相似照片的比對全部在手機上完成
- App 自己無法刪除檔案，刪除一律交給 Android 系統的確認畫面，預設先進系統垃圾桶（30 天內可救回）

## 安裝與首次設定

### 1. 安裝 APK（ColorOS）

1. 用手機瀏覽器打開 [Releases](https://github.com/hoonsor/APK-Photo/releases)，下載最新的 `PhotoSortBox-vX.Y.Z.apk`（或用 Obtainium，見下方「手機端更新」）。
2. 用「檔案管理」點開 APK。第一次會詢問是否允許這個來源安裝 → 允許。
3. ColorOS 可能跳出安全檢查（例如「來自外部來源的應用程式」），選「繼續安裝」或「仍要安裝」。
4. 選單名稱依 ColorOS 版本可能略有不同；若找不到，到「設定」搜尋「安裝未知應用程式」，替檔案管理開啟允許。

**更新**：用 App 內更新或 Obtainium，不用接線，見下方「手機端更新」。相簿與整理進度都會保留。
**LAB 版**（`build.sh --lab` 產生，名稱顯示「照片整理箱 LAB」）是測試新功能用的，可和正式版同時安裝，資料互不影響。

> 若安裝時出現「與現有的套件衝突」之類的訊息，代表簽章換過，必須先卸載舊版。
> **卸載會清掉相簿與整理進度**，請先到「更多 → 備份與還原」匯出備份，裝好新版再匯入。

### 2. 相片權限：一定要選「允許全部」

第一次開啟會要求「相片和影片」權限，請選**允許全部**。
如果選了「選取部分相片」，App 只看得到那幾張，畫面會提示你重新授權。
事後要改：手機「設定 → 應用程式 → 照片整理箱 → 權限 → 相片和影片」→ 改成允許全部。

### 3. 拍攝地點（可選）

想看照片的拍攝地點時，在照片資訊的「位置」分頁按「允許讀取照片位置」。
Android 預設會把照片裡的 GPS 藏起來，必須另外允許。

## 手機端更新（不用接線）

v1.2.0 起，正式版由 GitHub Actions 編譯、用共用金鑰 `hoonsor-release.jks` 簽章，發布在 [Releases](https://github.com/hoonsor/APK-Photo/releases)。手機有兩種更新方式，擇一或並用：

**App 內更新（建議）**
- 每天第一次開啟 App 時在背景檢查一次；有新版會跳出版本號與更新說明，可選「下載並更新」「稍後」或「略過此版」。
- 「更多 → 設定」裡的「App 更新」可隨時按「檢查更新」。
- 第一次更新時會引導你到「安裝不明應用程式」允許本 App，按返回鍵回到 App 後自動開始下載。
- 沒網路或 GitHub 無法連線時安靜略過，不影響整理。
- 更新完成後相簿與整理進度都會保留。

**Obtainium 設定**
1. 在手機安裝 [Obtainium](https://github.com/ImranR98/Obtainium/releases)。
2. 「Add App」→ App Source URL 填 `https://github.com/hoonsor/APK-Photo`。
3. 保持「Include prereleases」關閉（`latest` 是每次推送 main 自動編譯的測試版，不要追它）。
4. 若同一個 Release 未來有多個 APK，在「Filter APKs by Regular Expression」填 `PhotoSortBox-v.*\.apk`。
5. 新增後 Obtainium 會定期檢查，有新版時通知並一鍵安裝。

**從 v1.1.8 以前換到 v1.2.0（只需一次）**：v1.1.8 以前用的是舊金鑰 `keystore.p12`，v1.2.0 起換成共用金鑰，系統不允許直接覆蓋安裝。
1. 在舊版「更多 → 備份與還原」**匯出備份**，存到雲端硬碟或下載資料夾。
2. 解除安裝舊版（相簿與整理進度會清空，所以第 1 步一定要做）。
3. 從 [Releases](https://github.com/hoonsor/APK-Photo/releases) 下載 `PhotoSortBox-v1.2.0.apk` 安裝，允許相片權限。
4. 「更多 → 備份與還原」**匯入**剛才的備份檔。之後的版本都能直接更新。

## 畫面總覽

底部四個分頁：**照片**（預設）／**相簿**／**待刪**／**更多**。
v1.3.0 起沒有「整理」分頁：整理直接在照片檢視用上下滑完成（見下方「照片檢視」）。
照片頁和相簿頁左上角的 ☰ 可打開側邊選單（內容與「更多」相同）。

## 每個功能怎麼用

### 照片頁

- **照片牆**：每天第一張前面有一格日期（年/月、日、星期），每個月有標題，標題右側「逐張整理」會從那個月最新的一張打開照片檢視，接著用上下滑整理。
- **雙指縮放**：兩指張開→每列變少、照片變大；捏合→每列變多（2～7 張）。App 會記住，相簿內頁也一起套用。
- **跳轉**：上方年份按鈕點一下跳到那年，再點月份跳到那個月；右上角浮動標籤顯示目前位置。
- **搜尋**：可輸入資料夾名稱、檔名，或日期 `2023`、`2023-07`、`2023/7/15`、`2023年7月15日`、`20230715`。
- **篩選**：全部／未整理／已保留／待刪、截圖、**LINE**（從 LINE 存下來的）、影片、大檔案（>8MB）、指定資料夾；排序：最新／最舊／最大。
- **點一下**：開啟照片或影片。

### 多選與加入相簿

- **進入多選**：長按任一張；或在照片頁**往右滑**，左側「加入相簿」欄會從左邊滑進來。
- **選照片**：點照片任何位置都可以勾選或取消；**點日期格**一次選整天（整天選滿時日期格變藍，再點一次取消）；
  已在多選中時**長按還沒選的照片**，會把最近一張已選的到這一張之間整段選起來。
- **加入相簿**（三種方式）：
  1. 點左側相簿欄的某一本 → 選取的照片加入。
  2. 點左側最上面的「＋ 建立相簿」→ 輸入名稱，建立並加入。
  3. **長按任一張已選的照片**，照片會疊成一疊，拖到左側相簿上放開；拖到「建立相簿」會建立新相簿。拖到相簿欄上下邊緣會自動捲動，拖到空白處放開就取消。
- **上方工具列**：✕（取消多選）、已選數量與大小、全選、**分享**。
- **下方工具列**：標為保留、清除標記、移到資料夾（實際搬移檔案，需系統確認）、加入待刪。
- **收起**：沒有選取任何照片時往左滑可收起相簿欄；有選取時請按左上 ✕，避免手滑把選好的照片取消掉。

### 相簿

- **相簿頁**：所有相簿的卡片牆；右下 ＋ 建立；右上 ⋮ 可建立／重新命名／複製／刪除；長按卡片也能管理。
- **喜好項目**是內建相簿：在照片檢視按 ☆ 就會收進去，不能改名或刪除。
- **相簿內頁**：上方是封面、名稱、「N 張照片、M 部影片」；下方「＋ 新增照片」（可只看照片或影片、可隱藏已在相簿的）與「分享相簿」。
  長按進入多選後可：分享、移出相簿、設為封面、加入其他相簿、加入待刪。
- **相簿和資料夾不一樣**：相簿是 App 裡的清單，不搬動檔案；刪除相簿不會刪到照片。資料夾是檔案真正的位置（相機、截圖、LINE）。

### 照片檢視

- **手勢**（照片剛好符合螢幕、沒有放大時）：
  - **往左滑／往右滑**：下一張（較舊）／上一張（較新）。
  - **往上滑**：加入待刪清單，這張會從左右滑的範圍拿掉，下一張補上來（例如 3 張裡第 2 張加入待刪，從第 3 張往回滑會直接到第 1 張）。
    下方會出現「已加入待刪清單｜復原（10）」，10 秒內按「復原」就取消，照片放回原位。
  - **往下滑**：打開照片編輯器（影片不能編輯）。
  - 拖曳時照片會跟著手指移動，畫面中間會提示「放開：加入待刪／編輯照片」；沒滑夠就放開會彈回去，什麼都不做。
- **照片放大時**（雙指張開或點兩下）：上下左右滑都只是**拖曳**看照片的其他部分，不會換張也不會觸發動作；
  點兩下或捏合縮回原大小後，上面的手勢才會恢復。
- 點一下隱藏／顯示上下工具列。
- 已經在待刪清單的照片不會出現在左右滑的範圍裡（從「待刪」篩選點進去看時例外）。
- **只整理還沒整理過的**：在照片頁的篩選選「未整理」，再點開照片，左右滑就只會在未整理的照片之間切換。
- **影片**：按中間的播放鍵在 App 內播放，可上一部／下一部；格式不支援時會改用其他播放器。
- **下方按鈕**：
  - **資訊**：四個分頁——資訊（檔名、拍攝時間、解析度、曝光、光圈、ISO、閃光燈、白平衡、焦距、機型；影片顯示長度與位元率）、
    位置（座標＋「在地圖 App 中開啟」「複製座標」）、相簿（在哪些相簿，可加入／移出）、裝置（手機型號與完整路徑）。
  - **喜好**：加入或移出喜好項目。
  - **加入相簿**：勾選要放在哪些相簿，也可直接建立新相簿。
  - **編輯**：打開照片編輯器（和往下滑一樣）。
  - **分享**：系統分享選單。
  - **刪除**：選「加入待刪清單」或「立即移到系統垃圾桶」（一樣要在系統畫面確認）。
- **右上 ⋮**：加入待刪清單、清除標記、編輯照片、用其他 App 播放（影片）。

### 照片編輯

- 進入方式：照片檢視**往下滑**、按下方「編輯」，或 ⋮ →「編輯照片」。
- **工具**（最下面一排，可左右捲動）：畫筆、螢光筆（半透明寬筆）、方框、圓框、箭頭、文字、**馬賽克框**、**馬賽克筆**。
- **馬賽克**：「馬賽克框」拖曳框出範圍；「馬賽克筆」用手指塗抹，粗細用滑桿調。格子大小固定（約照片短邊的 1/40），取的是原照片的顏色，所以蓋在其他標註上時也會一起遮住。
- **顏色**：紅、橘黃、螢光黃、綠、藍、紫、白、黑（可左右捲動）。
- **粗細**：拖曳滑桿連續調整（1～100），右邊的預覽格會用目前的顏色顯示實際粗細；選文字工具時調的是字級。
  App 會記住上次用的工具、顏色、粗細。
- **文字**：選「文字」後點照片上要放的位置，輸入文字（可換行）；點已經有的文字可以修改或刪除，按住拖曳可以移動。
- 右上角 **↶ 復原／↷ 重做**。
- **另存**：存成一張**新照片**，放在原照片同一個資料夾，檔名是「原檔名_編輯_日期時間」，拍攝時間沿用原照片，
  所以在照片牆上會排在原照片旁邊；回到照片檢視時往左滑就看得到。**原照片不會被改動。**
- 沒存檔就按 ✕ 或返回，會問要「放棄」「另存後離開」還是「繼續編輯」。
- 限制：很大的照片會先縮到最長邊 4096 像素再編輯（存出來的照片也是這個大小）；不能裁切、旋轉。

### 從哪一張開始整理（原本的「從某張開始」）

- 直接在照片頁點開想開始的那一張就好，往左滑是往較舊的照片、往右滑是往較新的照片。
- 月份標題右邊的「逐張整理」：從那個月開始。
- 「更多 → 資料夾」長按資料夾：從那個資料夾最新的一張開始，左右滑只在那個資料夾裡切換。

### 待刪

- 列出所有待刪的照片與可釋放空間；可挑選後還原，或全部還原。
- **清空待刪清單**：交給 Android 系統確認，預設先進系統垃圾桶（30 天內可在系統相簿救回）。設定裡可改成直接永久刪除。
- **清空系統垃圾桶**：只能清除「透過本 App 丟進去」的項目——Android 只允許系統相簿看到其他 App 丟的檔案。

### 更多

- **資料夾**：手機上實際的資料夾卡片；點了在照片頁只看那個資料夾，長按直接逐張整理（只在那個資料夾裡切換）。
- **重複／相似照片**：找出連拍、重複存檔的照片並分組，每組自動建議保留解析度最高、檔案最大或最新的一張。
- **備份與還原**：見下一節。
- **設定**：手勢說明、顯示影片、震動回饋、清空時直接永久刪除、重新掃描媒體庫、清除所有整理紀錄、App 更新。
- **說明**：常見問題。

## 備份與還原

相簿、喜好項目、已保留／待刪的標記**只存在 App 裡**。卸載 App 或換手機時會消失，所以請定期備份。
備份只有一個小檔案（不含照片本身）。

**匯出**：更多 → 備份與還原 → 匯出備份檔 → 選存放位置（下載、Google 雲端硬碟、Dropbox 都可以）。
檔名預設為 `照片整理箱備份_年月日_時分.json`。

**還原**：更多 → 備份與還原 → 從備份檔還原 → 選檔案 → 看過摘要（找到幾本相簿、幾張對得上）後按「還原」。

- 還原是**合併**：同名相簿會把內容併在一起，不會刪掉你現有的相簿。
- 換手機也對得上：照片用檔名、大小、拍攝時間比對，只要照片有一起搬過去就行。
- 對不上的照片（已刪除或還沒搬過來）會略過，摘要會告訴你幾張。

> 目前**沒有自動備份**，要自己按匯出。定期自動備份到雲端硬碟／Dropbox 已在規劃，尚未實作。

## 常見問題

**相簿和資料夾有什麼不同？**
資料夾是檔案真正存放的位置（Camera、Screenshots、LINE）。相簿是 App 裡的整理清單：加進相簿不會搬動或複製檔案，
同一張可以同時在好幾本，照片和影片也能放一起，刪除相簿不會刪到照片。

**為什麼最右邊的照片點不到／被切掉？**
v1.1.1、v1.1.2 已修正。請更新到最新版。

**為什麼看不到地圖？**
內嵌地圖要把位置傳給地圖服務，而本 App 的網路只用來檢查更新、照片與位置都不會被傳出去，所以「位置」只顯示座標，按「在地圖 App 中開啟」交給 Google 地圖。

**為什麼看不到拍攝地點？**
要先在「位置」分頁允許讀取照片位置；另外，從通訊軟體下載的照片常被移除位置資訊，拍攝時沒開定位也不會有。

**影片播不出來？**
少數格式（部分 HEVC、10-bit HDR）手機內建播放器不支援，App 會自動改用其他播放器；也可以在 ⋮ 選「用其他 App 播放」。

**刪除會不會不小心刪錯？**
不會直接刪。照片先進「待刪」清單，清空時才交給 Android 系統確認，預設還會先進系統垃圾桶，30 天內都救得回來。

**「清空系統垃圾桶」為什麼清不到其他 App 丟的檔案？**
Android 只讓系統相簿看到其他 App 丟進垃圾桶的檔案，這是平台限制。

**LINE 篩選沒抓到我的 LINE 照片？**
App 依「資料夾名稱是 LINE」或路徑在 `Pictures/LINE`、`Movies/LINE` 判斷。如果你的手機存在別的資料夾，請告訴開發者資料夾名稱。

**更新後相簿不見了？**
同一把簽章的新版覆蓋安裝不會清資料。如果你是卸載後重裝（例如從 v1.1.8 換到 v1.2.0），資料會清空，請從備份檔還原。

**更新時顯示「簽章與目前安裝的不同」？**
手機上是 v1.1.8 以前的舊金鑰版本，請照「手機端更新」裡「從 v1.1.8 以前換到 v1.2.0」的步驟做一次。

**為什麼 v1.2.0 起有網路權限？**
只用來向 GitHub 檢查與下載 App 更新（每天最多查一次），照片、相簿、位置都不會經過網路。

## 如何發新版

1. 修改 `AndroidManifest.xml` 的 `android:versionCode`（例如 `10201`）與 `android:versionName`（例如 `1.2.1`）。設定頁顯示的版號會自動跟著變。
2. 在 `PROJECT_STATUS.md` 的「版本詳細紀錄」最上面新增 `### v1.2.1 — 日期` 段落（版本歷程摘要表也加一列），這段文字會自動成為 Release 的更新說明（也就是 App 內更新對話框顯示的內容）。
3. 提交並推送 main，接著推送同名 tag：

   ```bash
   git tag v1.2.1
   git push origin main v1.2.1
   ```

4. GitHub Actions 會在 ubuntu 上下載 build-tools 與 android.jar、跑 `tests/run.sh`、用 `build.sh` 打包並以共用金鑰簽章，發布 `PhotoSortBox-v1.2.1.apk`。tag 與 `versionName` 不一致時 CI 會直接失敗，避免 App 一直以為有新版。

其他說明：
- 每次推送 main 都會更新名為 `latest` 的預先發行版（`PhotoSortBox-latest.apk`），給想搶先測試時手動下載；App 內更新與 Obtainium 預設都不會把它當成新版。
- 簽章 Secrets（`SIGNING_KEYSTORE_B64`、`SIGNING_STORE_PASSWORD`、`SIGNING_KEY_ALIAS`、`SIGNING_KEY_PASSWORD`）已由倬寫入 repo。沒有 Secrets 時 CI 用臨時金鑰（只確認能編譯），推 tag 時直接失敗。

## 自行建置（開發者）

```bash
# 方式 1：Android SDK（倬的電腦、GitHub Actions）。需要 JDK 17 或 21、build-tools 36.0.0、platforms;android-35
export ANDROID_HOME=<Android SDK 路徑>
export SIGNING_KEYSTORE_PATH=<hoonsor-release.jks 路徑> SIGNING_STORE_PASSWORD=<密碼> SIGNING_KEY_ALIAS=<別名> SIGNING_KEY_PASSWORD=<密碼>
bash build.sh                         # 正式版 → build/photo-sort-box.apk
bash build.sh --lab                   # 實驗版（可與正式版同時安裝）
bash tests/run.sh                     # 純邏輯測試

# 方式 2：連不到 Google 的雲端容器：先 bash setup.sh 從 npm 取得工具鏈到 ../tools，其餘相同
```

簽章金鑰與密碼不在 repo 裡，詳見 `AGENTS.md` 第 3 節。
